# Hericles Nutricionista — Landing Page React + Vite

## Como rodar localmente

```bash
npm install
npm run dev
```

## Como fazer o build para produção

```bash
npm run build
```

Os arquivos finais ficam na pasta `dist/`.

## Deploy no Vercel (recomendado)

1. Suba o projeto no GitHub
2. Acesse [vercel.com](https://vercel.com) → Import project
3. Selecione o repositório → Vercel detecta Vite automaticamente
4. Clique em **Deploy** ✅

## Personalizar

- **Número do WhatsApp**: edite as constantes `WA_LINK`, `WA_ONLINE`, `WA_PRESENCIAL` no início de `src/App.jsx`
- **Fotos**: substitua os arquivos em `public/img/`
- **Logo**: substitua `public/img/logo-dark.png` e `public/img/logo-light.png`
- **Textos**: edite diretamente em `src/App.jsx`
